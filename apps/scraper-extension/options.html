Deal Scraper & Affiliate – Settings

1. Google Drive & Google Sheet (no sign-in)

Google does not let any app upload to Drive with only a shared link. So you add a small script to your own Google account once. It saves the images and writes the sheet rows for the extension.

  1. Open script.google.com → New project.
  2. Delete what is there in Code.gs and paste the script (Copy script). Then + → HTML, name it Dashboard, and paste Copy dashboard into it. Press Save.
  3. Deploy → New deployment → gear icon → Web app. Execute as: Me. Who has access: Anyone. Deploy, then Authorize access and allow.
  4. Copy the Web app URL (ends in /exec) into the box below. Open the same URL in your browser or phone: that is your dashboard. The first time, choose an access key and enter it below too.
  5. Already set up before? Paste both files again, then Deploy → Manage deployments → ✎ → Version: New version → Deploy. The URL stays the same.

5. Conversion per store

Choose how each store's links are converted. Auto = Amazon → your tag + SiteStripe, every other store → ExtraPe. When you get your own affiliate program (for example Flipkart Affiliate), switch that store to My link pattern (e.g. {{url}}&affid=yourid) or My converter page (the page where you paste a link and press Convert, like ExtraPe).
