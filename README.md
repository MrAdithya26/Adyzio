# Adyzio

Code, apps and updates for **[Adyzio](https://www.adyzio.com)** — the affiliate deals hub of ABD Innovations.

Adyzio publishes product deals and recommendations using its own affiliate links (Amazon Associates and ExtraPe for Flipkart, Myntra, Shopsy and other Indian stores). Planned next: dropshipping and Adyzio's own products.

## Folders

| Folder | What goes here |
|---|---|
| `website/` | Website code: pages, product cards, deal layouts, categories |
| `apps/` | Any apps or tools built for Adyzio |
| `content/` | Product posts, deal descriptions, comparisons (English and Telugu) |
| `data/affiliate-links/` | Affiliate link lists for bulk updates |
| `docs/` | Plans, decisions and notes |

## Rules

- Every page with affiliate links carries a clear affiliate disclosure (required by Amazon Associates).
- No invented prices, discounts or specs. Anything to check against the store page is marked **VERIFY**.
