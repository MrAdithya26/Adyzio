=== Adyzio Core ===
Version: 1.6.0
For: adyzio.com (ABD Innovations)

Which version am I running?  WordPress → Settings → Adyzio (top box), or Plugins → "Adyzio Core" row.
Uploading an update:  Plugins → Add New Plugin → Upload Plugin → choose adyzio-core-X.Y.Z.zip → "Replace current with uploaded".

== Features in 1.6.0 ==
Homepage
* Flipkart-style layout in Adyzio colours: top-left switcher (Adyzio, Shopping, Travel, Finance, Hosting, Services), search, Telugu switch, Saved.
* Category bar for all main categories with a mega-menu (sub categories as columns, child categories under each).
* Banner carousel, Deals of the Day, "Best of" panel per category, Shop by budget, Top stores, partner pages for Travel/Finance/Hosting.
* Category pages with breadcrumbs (Main > Sub > Child), filters and every matching product.
* Deal cards: store logo, Buy Now, share (WhatsApp, Telegram, email, copy link), save; prices shown only for 24 hours after checking.

Categories
* 726 categories in 3 levels (Settings → Adyzio → Install the Adyzio category list); installs by itself after an update.

Adding products
* Deal details box in the post editor (affiliate link, store, price, MRP, image, Good for, check list, deal end time).
* Tools → Adyzio Import: upload your scraper's .xlsx or a CSV; live % progress with a line graph; products are filed into child categories.
* Google Sheet auto-sync: updates products and publishes them when their Affiliate Link is filled in.
* No duplicates: the same product is updated, never posted twice. "Clean up duplicates" button.

SEO
* Rank Math: SEO title = product name, focus keyword = short product name (+ "… price", child category), meta description, short URL for new imports, one-line intro for empty products. "Apply SEO to all products" button.

Compliance
* Affiliate links use rel="sponsored nofollow"; disclosure line on every deal; store links are never used as Buy links.
